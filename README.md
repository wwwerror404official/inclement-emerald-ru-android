# Pokémon Inclement Emerald — русский перевод и освещение для Android

Неофициальная Android-сборка на базе **Inclement Emerald v1.13 (Custom 1.5 Update)**. Игра включена в APK. После установки её можно открыть по отдельной иконке **Inclement RU**.

## Скачать и запустить

1. На странице [Android-беты](../../releases/tag/v0.1.0-android-beta) скачай из **Assets** файл `Inclement_Emerald_RU_Lighting_v0.1.0-android.apk`.
2. Установи APK на телефон с **Android 8.0 или новее** и поддержкой **ARM64**.
3. Открой **Inclement RU** и нажми **Играть**. Для переноса прогресса можно импортировать обычный внутриигровой файл `.sav`.

## Что входит в сборку

- Русские диалоги, меню, имена покемонов и тренеров, приёмы, способности, предметы, Pokédex и боевые сообщения.
- Уличное освещение с GPU-рендерером из 0.3.3. Работают смена времени суток, динамические тени, свет фонарей и блики на воде.
- Настраиваемое сенсорное управление, скорость до ×4 и импорт обычных сохранений.
- Игровые механики и типы покемонов из исходной Custom 1.5.

**Перевод сделан с помощью ИИ** на основе русской локализации Emerald от kozzztya. Возможны опечатки, неровные формулировки, английские строки и ошибки вёрстки. В бете используется интерпретатор GBARecomp. Скорость на телефоне может отличаться от личной 0.3.3. Игровые сцены с рендерером проверены на ПК.
